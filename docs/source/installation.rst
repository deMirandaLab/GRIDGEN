Installation
============

GRIDGENE requires Python >= 3.10.

Install from source
-------------------

.. code-block:: bash

    git clone https://github.com/deMirandaLab/GRIDGENE.git
    cd GRIDGENE
    pip install -e .

Dependencies are installed automatically. They include numpy, pandas, scipy,
matplotlib, scikit-learn, scikit-image, opencv-python, shapely, and others
as listed in ``requirements.txt``.
